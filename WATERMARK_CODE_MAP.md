Core idea in Chapter 4:

- Prefix-carrier watermarking: use a short visible-byte prefix class instead of exact token identity.
- Adaptive prefix granularity: choose short prefix length while retaining enough entropy.
- Fingerprint-driven PRF partition: use a local visible-text fingerprint plus prefix UID to decide green/red partition.
- Detection: reconstruct prefix UID and fingerprint on the received text, then compute a z-score.
- Robustness target: token-level and character-level edits that cause tokenization drift.

Key files:

```text

/home/star/jf/watermark/MarkLLM/watermark/bytekgwV6/logits_processor.py
/home/star/jf/watermark/MarkLLM/watermark/bytekgwV6/detector.py
/home/star/jf/watermark/MarkLLM/watermark/bytekgwV6/prf.py
/home/star/jf/watermark/MarkLLM/watermark/bytekgwV6/token_bytes.py
/home/star/jf/watermark/MarkLLM/watermark/bytekgwV6/config.py
```

Responsibilities:

- `watermark.py`: wrapper for generation and detection.
- `logits_processor.py`: adds `delta` bias to green tokens during generation.
- `detector.py`: reconstructs prefix class and PRF decision, then computes z-score.
- `prf.py`: robust local-context fingerprint and token-prefix vector partitioning.
- `token_bytes.py`: maps token IDs to visible-byte sequences and prefix IDs.
- `config.py`: parses ByteKGWv6 parameters.

Main config:

```text
/home/star/jf/watermark/config/ByteKGWv6.json
```

Observed settings:

```text

k_weight_mode = linear
decision_margin_bits = 12
normalize_whitespace = true
add_special_tokens = true
z_threshold = 4.0
```
